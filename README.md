# Gal Impex LLC Website

This repository contains the bilingual (Mongolian + English) corporate website for **Fire Impex LLC (Гал Импекс ХХК)** built with Next.js and Tailwind CSS.

## Routes
- `/` language selection landing page
- `/mn` Mongolian content
- `/en` English content

## Local development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
